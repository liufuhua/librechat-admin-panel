# LibreChat Admin Panel 设计系统

## 产品与页面

这是企业 AI 管理后台。数据查询模块面向管理员，目标是配置只读数据源、查看数据域版本和授权、执行受控发布/回滚并阅读管理审计。普通聊天用户不看到此入口。

## 视觉基线

- 延续现有 LibreChat Admin Panel：紧凑左侧导航、白/深灰面板、细灰边框、低阴影。
- 使用 Click UI 和 Tailwind CSS 4；浅色主强调色为 `#437eef`，深色主强调色为 `#faff69`。
- 表格是主阅读结构：表头清晰、行距紧凑、状态用文本和图标共同表达，不只依赖颜色。
- 危险动作使用确认对话框；Secret、DSN、Token 永不显示。
- 可访问性：所有图标按钮有标签，键盘可操作，错误和加载状态可被读屏读取。

## Task 13 首个页面

`/data-query` 默认展示“数据源”Tab：数据源表、环境/风险/启用状态和“新增数据源”按钮；另有“数据域与版本”“授权”“审计”Tab。对尚未由 Task 11 提供的接口展示明确的受控占位状态，不伪造数据或操作结果。
